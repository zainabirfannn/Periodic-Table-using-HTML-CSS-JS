# 🌸 Pastel Periodic Table of Elements (No-Scroll Fullscreen)

A clean, pretty, and simple **Periodic Table of Elements** built with pure **HTML**, **CSS**, and **simple JavaScript**, designed to fit seamlessly on your screen with **no scrollbars**.

---

## ✨ Features

- **🖥️ Zero Scrolling**:
  - The entire periodic table, header, and pastel legend dynamically scale to fit 100% of the screen height and width without any horizontal or vertical scrolling.

- **🎨 Soft Pastel Aesthetic**:
  - Pleasant, eye-friendly pastel colors for every chemical category:
    - **Alkali Metals**: Soft pink
    - **Alkaline Earth**: Soft peach / apricot
    - **Transition Metals**: Soft butter yellow
    - **Post-Transition Metals**: Soft sky blue
    - **Metalloids**: Soft aqua / turquoise
    - **Reactive Nonmetals**: Soft mint green
    - **Noble Gases**: Soft lavender
    - **Lanthanides**: Soft rose pink
    - **Actinides**: Soft lilac violet
    - **Superheavy**: Soft warm slate

- **👆 Simple Tap / Click Interaction**:
  - Tap or click on any of the 118 elements to open a clean information card showing:
    - Large pastel symbol badge
    - Element name & category
    - Atomic number & atomic mass
    - Standard state (Solid / Liquid / Gas)
    - Period & Group location
    - Short, easy-to-read fun fact / description

- **🔍 Simple Search Box**:
  - Filter and highlight elements quickly by typing the name (*Gold*), symbol (*Au*), or atomic number (*79*).

- **🧑‍💻 Beginner-Friendly Code**:
  - Written in simple, readable vanilla HTML, CSS, and basic JavaScript.
